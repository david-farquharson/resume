# David A. Farquharson | Interactive Resume

An AI-powered interactive resume showcasing my experience in defense leadership, strategic planning, and technology.

🔗 **Live Site:** [david-farquharson.github.io/resume](https://david-farquharson.github.io/resume)

## Features

- ✨ **AI Chat** - Ask questions about my experience and get AI-powered answers
- 📋 **Job Fit Analyzer** - Paste a job description to see how my experience aligns
- 🎖️ **Strategic & Defense Expertise** - PPBE, FMS, Security Cooperation, COR experience
- 💻 **Technical Expertise** - AI/Automation, Infrastructure, Web3, Development

## Tech Stack

- React 18
- Vite
- Claude API (for AI features)
- GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

## Deployment

This site auto-deploys to GitHub Pages on push to `main` branch via GitHub Actions.
